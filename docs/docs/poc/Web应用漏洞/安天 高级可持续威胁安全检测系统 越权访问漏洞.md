# 安天 高级可持续威胁安全检测系统 越权访问漏洞

## 漏洞描述

安天 高级可持续威胁安全检测系统 存在越权访问漏洞，攻击者可以通过工具修改特定的返回包导致越权后台查看敏感信息

## 漏洞影响

```
安天 高级可持续威胁安全检测系统
```

## 网络测绘

```
title="高级可持续威胁安全检测系统"
```

## 漏洞复现

登录页面如下



![](https://raw.githubusercontent.com/sunwu57/tuchuang/main/img/20250326115529010.png)



其中抓包过程中发现请求的一个身份验证 Url



![](https://raw.githubusercontent.com/sunwu57/tuchuang/main/img/20250326115529011.png)

```plain
{"role": "", "login_status": false, "result": "ok"}
```



其中 **login_status 为 false**, 将参数使用 Burp 替换响应包为 **true**



![](https://raw.githubusercontent.com/sunwu57/tuchuang/main/img/20250326115529012.png)

请求 **/api/user/islogin** 时成功越过身份验证



![](https://raw.githubusercontent.com/sunwu57/tuchuang/main/img/20250326115529013.png)



再次访问首页验证越权漏洞



![](https://raw.githubusercontent.com/sunwu57/tuchuang/main/img/20250326115529014.png)
