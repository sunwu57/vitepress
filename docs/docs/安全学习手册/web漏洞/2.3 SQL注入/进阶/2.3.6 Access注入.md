# **<font style="color:rgb(38, 38, 38);">Access数据库特性</font>**
### **<font style="color:rgb(56, 158, 13);">Access数据库结构</font>**
<font style="color:rgb(38, 38, 38);">1> Access数据库是单一数据库,因此没有库名,数据库中的结构为: </font>**<font style="color:rgb(38, 38, 38);">表-->列-->数据，</font>**<font style="color:rgb(38, 38, 38);">myql的结构为:</font>**<font style="color:rgb(38, 38, 38);">库-->表-->列-->数据。</font>**<font style="color:rgb(38, 38, 38);">  
</font><font style="color:rgb(38, 38, 38);">2> Access数据库没有像mysql里information_schema这样的库记录所有表的信息,因此注入方法只能靠猜或者逐字盲注来猜解。</font>

### **<font style="color:rgb(56, 158, 13);">Access数据库判断</font>**
<font style="color:rgb(38, 38, 38);">1> 可以通过该网站使用的脚本语言判断如asp基本和Access配合使用,也可以通过Access特有的表判断,Access特有的表是:</font>**<font style="color:rgb(38, 38, 38);">msysobjects</font>**<font style="color:rgb(38, 38, 38);">  
</font><font style="color:rgb(38, 38, 38);">2> 判断语句:exists(select*from msysobjects) //如果该表存在则是Access数据库  
</font><font style="color:rgb(77, 77, 77);"> (select count(*) from msysobjects) >0 //返回正确</font><font style="color:rgb(38, 38, 38);">则是Access数据库</font>

### **<font style="color:rgb(56, 158, 13);">Access注释符</font>**
<font style="color:rgb(0, 0, 0);">Access数据库没有注释符，因此我们在注入中查询数据时，如果需要使用注释，那么我们将无法使用那些常见的注释符：/**/ ，-- 或者 #。</font><font style="color:rgb(38, 38, 38);">  
</font><font style="color:rgb(0, 0, 0);">	然而，我们有时候可以使用Null,也就是%00，来移除查询语句里面一些无用的部分。但是在有些情况便无法使用这种方式，例如PHP里面开启了magic_quote_gpc参数（魔术引号），那么便会在Null前面添加反斜杠，从而导致失去意义；</font>
