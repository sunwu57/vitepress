# D-Link AC管理系统 默认账号密码

## 漏洞描述

D-Link AC管理系统存在默认账号密码，可被获取敏感信息

## 漏洞影响

```
D-Link AC管理系统
```

## 网络测绘

```
"AC集中管理平台"  && body="D-Link路由器管理页"
```

## 漏洞复现

默认口令为 admin:admin
