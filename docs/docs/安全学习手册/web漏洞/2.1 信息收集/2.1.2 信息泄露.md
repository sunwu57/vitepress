### **<font style="color:rgb(38, 38, 38);">WEB-INF/web.xml泄露</font>**
<font style="color:rgba(0, 0, 0, 0.8);background-color:rgb(240, 240, 240);">WEB-INF</font><font style="color:rgba(0, 0, 0, 0.8);">是Java的WEB应用的安全目录，如果想在页面中直接访问其中的文件，必须通过web.xml文件对要访问的文件进行相应映射才能访问。</font><font style="color:rgb(38, 38, 38);">  
</font><font style="color:rgba(0, 0, 0, 0.8);background-color:rgb(240, 240, 240);">WEB-INF</font><font style="color:rgba(0, 0, 0, 0.8);">主要包含一下文件或目录：</font>

```sql
WEB-INF/web.xml : Web应用程序配置文件, 描述了servlet和其他的应用组件配置及命名规则.
WEB-INF/database.properties : 数据库配置文件
WEB-INF/classes/ : 一般用来存放Java类文件(.class)
WEB-INF/lib/ : 用来存放打包好的库(.jar)
WEB-INF/src/ : 用来放源代码(.asp和.php等)
```
