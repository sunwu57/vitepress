# 0x00 php反序列化简介
<font style="color:rgb(68, 68, 68);">php 反序列化基本上是围绕着serialize()、unserialize()这两个函数展开的，还有PHAR协议用于解析 phar 文件、phar 文件的 meta-data 字段存在反序列化漏洞，可以使用协议读取文件触发反序列化。</font><font style="color:rgb(38, 38, 38);">  
</font><font style="color:rgb(68, 68, 68);">那么什么是序列化呢？序列化就是将一个对象变成可以传输的字符串，而反序列化其实就是</font><font style="color:rgb(223, 42, 63);">将序列化得到的字符串再转变成对象。</font>

<font style="color:rgb(38, 38, 38);">在这里写了一个 class，这个 class 中存有一些变量，当这个class被实例化之后，在使用过程中，里面的一些变量发生了改变，如果以后某些时候还会用到这个变量，我们让这个class一直不销毁，就会浪费系统资源。而如果我们将这个对象序列化，将其保存成一个字符串，当你需要使用的时候，再将其反序列化为对象就可以了</font><font style="color:rgb(38, 38, 38);">  
</font><font style="color:rgb(68, 68, 68);">首先上例子：</font>

```php
<?php

class DemoClass{
public $name = "test";
public $sex = "man";
public $age = "24";
}
$example = new DemoClass();
$example->name = "aaron";
$example->sex = "woman";
$example->age = 22;

echo serialize($example);
?>
```

<font style="color:rgb(68, 68, 68);">在这里，我们首先创建了一个DemoClass，里面存了一些数据，然后我们实例化了一个对象，并将这个对象里的信息改变了，当我们还需要使用这个实例的话，就将序列化（serialize）后的字符串存起来，需要使用的时候再反序列化（unserialize）出来就可以了。</font><font style="color:rgb(38, 38, 38);">

## **<font style="color:rgb(38, 38, 38);">PHP类中魔术方法</font>**
```php
__construct():创建对象的时候触发
__destruct():对象被销毁时触发
__call():当调用对象不存在的方法时，自动调用此方法
__callStatic():在静态上下文中调用不可访问的方法时触发
__get()：获得一个类的成员变量时调用
 __set()：设置一个类的成员变量时调用
__isset():在不可访问的属性上调用isset()或empty()触发
__toString():当将对象以字符串输出时，自动调用此方法
__wakeup():当对象被反序列化的时候，自动调用此方法
 __callStatic()：用静态方式中调用一个不可访问方法时调用 
__unset()，当对不可访问属性调用unset()时被调用。
 __sleep()，执行serialize()时，先会调用这个函数 
__wakeup()，执行unserialize()时，先会调用这个函数 
 __invoke()：调用函数的方式调用一个对象时的回应方法
 __set_state()：调用var_export()导出类时，此静态方法会被调用。
__clone()：当对象复制完成时调用 
__autoload()：尝试加载未定义的类
__debugInfo()：打印所需调试信息
```

## **<font style="color:rgb(38, 38, 38);">PHP反序列化</font>**
<font style="color:rgb(38, 38, 38);">在PHP中其实反序列化和序列化差不多，也是使用</font><font style="color:rgb(38, 38, 38);">unSerialize()函数，将一个固定格式的字符串的字节序列存储转化为一个对象</font><font style="color:rgb(38, 38, 38);">  
</font><font style="color:rgb(38, 38, 38);">同样存在无类反序列化和有类反序列化，当然实现起来做法是一样得，就不都展示了</font>

```php

?>
```

```python
在PHP中，当一个对象被反序列化时，会按照以下顺序执行魔术方法：

__wakeup(): 当对象被反序列化时，这个方法会被调用。你可以在这个方法中执行一些初始化任务。

__construct(): 如果在反序列化对象时没有定义__wakeup()方法，那么__construct()方法会被调用。但是，如果定义了__wakeup()方法，那么__construct()方法就不会被调用。

__destruct(): 当对象不再被使用，或者脚本执行完毕时，这个方法会被调用。你可以在这个方法中执行一些清理任务。

注意：__sleep()方法在序列化时被调用，而不是在反序列化时。
```

</font><font style="color:rgb(38, 38, 38);">再仔细观察，开始条件判断我们输入的值用的是</font>`<font style="color:rgb(38, 38, 38);">===</font>`<font style="color:rgb(38, 38, 38);">,就是绝对等于，类型和值都需要满足，但是后面</font>`<font style="color:rgb(38, 38, 38);">process()</font>`<font style="color:rgb(38, 38, 38);">方法里用的</font>`<font style="color:rgb(38, 38, 38);">==</font>`<font style="color:rgb(38, 38, 38);">来判断，所以这一点我们就可以绕过强制转换1，回到</font>`<font style="color:rgb(38, 38, 38);">read()</font>`<font style="color:rgb(38, 38, 38);">函数中需要</font>`<font style="color:rgb(38, 38, 38);">$filename</font>`<font style="color:rgb(38, 38, 38);">参数的值，正好在类中存在这个成员变量  
</font><font style="color:rgb(38, 38, 38);">所以我们就需要构造特定类，将它序列化后，以</font>`<font style="color:rgb(38, 38, 38);">get</font>`<font style="color:rgb(38, 38, 38);">形式传入str中，使他反序列化，并按我们的预期执行  
</font><font style="color:rgb(38, 38, 38);">我们需要，将类中$filename='flag.php',用于读取flag，将</font>`<font style="color:rgb(38, 38, 38);">$op=' 2'</font>`<font style="color:rgb(38, 38, 38);">用于绕过</font>`<font style="color:rgb(38, 38, 38);">===</font>`<font style="color:rgb(38, 38, 38);">判断，</font>`<font style="color:rgb(38, 38, 38);">$content</font>`<font style="color:rgb(38, 38, 38);">随意</font><font style="color:rgb(38, 38, 38);background-color:rgb(245, 245, 245);">

# <font style="color:rgb(38, 38, 38);">0x03 </font>**<font style="color:rgb(38, 38, 38);">安全开发的防范建议</font>**
<font style="color:rgb(38, 38, 38);">在安全开发中，防范php反序列化攻击，常用的建议包括以下几点：</font><font style="color:rgb(38, 38, 38);">  
</font><font style="color:rgb(38, 38, 38);">1、不要使用 unserialized() 反序列化来处理未知源的数据。应该使用其他安全的反序列化函数，如 JSON 解码 (json_decode()) 等。 </font><font style="color:rgb(38, 38, 38);">  
</font><font style="color:rgb(38, 38, 38);">2、对于从未知来源接收到的数据，必须进行数据验证，以避免恶意攻击。应该使用 PHP 序列化自定义数组（serialize()）的函数很容易被嵌入一个已在内部定义的 PHP 类名，这个类可能会被用户请求中的序列化字符串调用。 </font><font style="color:rgb(38, 38, 38);">  
</font><font style="color:rgb(38, 38, 38);">3、序列化的数据应该经过加密，以防止可能存在的中间人攻击，比如数据包嗅探。而且，加密的密钥应该存储在安全的位置。</font><font style="color:rgb(38, 38, 38);">  
  
</font><font style="color:rgb(38, 38, 38);">4、在执行反序列化的代码之前，请确保使用合适的输入校验，以确保没有输入到反序列化（unserialize()）函数的未知参数。</font><font style="color:rgb(38, 38, 38);">  
  
</font><font style="color:rgb(38, 38, 38);">下面是一个示例代码，演示如何以安全的方式使用反序列化功能。此示例使用json_decode()函数来解析JSON字符串，避免了使用可能存在漏洞的unserialize()函数：</font>

```php
//接收JSON数据
$serialized_data= $_POST['json_data'];

//解析并验证JSON数据
$data = json_decode($serialized_data, true);
if(!is_array($data)){
    die("Invalid input data");
}
```
