# 概述


使用chatGPT写论文需要一定的话术



# 流程


1. 提供专业，对论文的要求，是容易点还是要具有创造性



> 我是一个大学生,专业是网络专业，现在要写毕业论文，请为我提供5个容易写的选题
>



2. 选定题目，不满意可以重新生成



> 请把第5个生成论文摘要，字数300左右
>



3. 生成大纲



> 请根据以上摘要，查询相关文献，生成论文大纲
>



4. 逐步生成内容



> 请写出第一部分论文内容，要求正品论文的字数为15000字，请按比例写第一部分
>



5. 人工自行排版，自行添加文献和图，并进行修改



# 去重


1. 新建对话进行关键点提取



> 提炼出这段话的关键点和结论，简明扼要:  
xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
>



2. 在另一个对话窗口中，将给出的关键点和结论进行续写



> 将这些关键点和结论扩写成文字:  
关键点:  
xxxx  
结论: xxxxxxxxxxx
>
