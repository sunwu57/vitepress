```python
西欧字母符号，通过1个字节来表示。东亚字符通过至少两个字节来表示。GBK编码就是用两个字节来表示中文区字符的一个编码标准。

GBK编码依然采用双字节编码方案，其编码范围：8140－FEFE（高字节从81到FE，低字节从40到FE），剔除xx7F码位，共23940个码位。

条件
后台使用GBK编码的时候，存在着看不见的ascii码转换为GBK编码的转换过程，可以使用宽字节注入。

原理
编码转换存在着单字符被合并的情形

 反斜杠对应url编码%5c，是单字节的。
 在%5c前再加入一个单字节字符%dd（范围可以是81到FE之间），就成了%dd%5c
 而当后端使用GBK编码的时候，会将合理的两个单字节ANSCII字符解析成一个双字节的GBK编码字符
```

## 堆叠注入
### <font style="color:rgb(0, 0, 0);">什么是堆叠注入</font>
<font style="color:rgb(51, 51, 51);">堆叠注入(stacked injections)从名词的含义就可以看到应该是一堆sql语句(多条)一起执行，而在真实的运用中也是这样的，我们知道在</font>[mysql](https://cloud.tencent.com/product/cdb?from_column=20065&from=20065)<font style="color:rgb(51, 51, 51);"> 中，主要是命令行中，每一条语句结尾加“;”表示语句结束的，这样我们就想到了是不是可以多句一起使用就叫做堆叠注入</font>

**<font style="color:rgb(51, 51, 51);">不是每个</font>**[数据库](https://cloud.tencent.com/solution/database?from_column=20065&from=20065)**<font style="color:rgb(51, 51, 51);">环境都可以支持堆叠注入</font>**
